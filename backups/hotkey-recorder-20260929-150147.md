## 恢复建议

先在工作区新建空目录，解压后对照恢复，避免覆盖后续修改：

```sh
mkdir -p restore-hotkey-recorder
shasum -a 256 backups/hotkey-recorder-20260929-150147.tar.gz
tar -xzf backups/hotkey-recorder-20260929-150147.tar.gz -C restore-hotkey-recorder
```

检查并恢复所需源码后，按项目 README 重新构建。不要直接覆盖用户配置；本归档没有用户配置。
